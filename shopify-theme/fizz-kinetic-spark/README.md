# Fizz Kinetic Spark Theme

Shopify Online Store 2.0 theme ported from Google Stitch **Kinetic Spark** designs.

## Quick start

```bash
npm install
npm run import:assets   # download Stitch images
npm run build:css       # compile Tailwind → assets/kinetic-spark.css
shopify theme dev --store fizz-9820.myshopify.com
```

See [`docs/SHOPIFY-THEME.md`](../../docs/SHOPIFY-THEME.md) and [`scripts/SHOPIFY-STORE-SETUP.md`](scripts/SHOPIFY-STORE-SETUP.md).
