# 12 — Glossary

| Term | Meaning |
|------|---------|
| **GLTF** | 3D file format; our bottle export from Spline |
| **WebGL** | Browser 3D API; Three.js uses it |
| **Monochromatic theme** | Scene + UI share one color family per variant |
| **Variant** | One bottle finish (e.g. charcoal-black) |
| **R2** | Cloudflare object storage for large assets |
| **Glassmorphism** | Frosted UI via `backdrop-filter: blur()` |
| **Placeholder bottle** | Simple Three.js mesh when GLTF URL unset |
| **Rim glow** | Point light colored with `gradient.glow` behind bottle |
| **ScrollTrigger** | GSAP plugin for scroll-linked motion (optional on 3D page) |
