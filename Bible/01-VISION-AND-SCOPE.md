# 01 — Vision and scope

## Goal

Define what the 3D product page is and is not.

## Product

Desktop-first WebGL experience: Fizz bottle centered, water below, horizon behind, glass UI overlays, six bottle color variants (v1 boots on charcoal-black).

## In scope (v1)

- `/3d.html` isolated entry
- Three.js composite scene + procedural ocean fallback
- Monochromatic variant theming
- Glass UI with packaging copy
- R2-hosted bottle GLTF
- Bible documentation

## Out of scope (v1)

- Mobile-first 3D configurator
- Barba transitions from main site
- Committing 304 MB GLTF to git
- Editing `fizz5.webflow/`
- Full Spline React runtime in production
